code ini untuk tugas TK2

Flight.java, Hotel.java merupakan kelas data yang mencakup (Field, konstruktor, getter/setter)

Pembayaran.java merupakan interface yang menampilkan total harga ini kewajiban method

Pemesanan.java merupakan kelas induk abstract dan sealed

Flightpemesanan.java, HotelPemesanan.java meruapakan subclass dari flight.java dan hotel.java

PemesananNotFoundExcemption.java, NumberGenerator.java berfungsi untuk validate sebuah input data apakah sesuai atau tidak

TravelApp.java merupakan inti dari sebuah alur nya berfungsi untuk mencari, memesan atau membatalkan sebuah pesanan

Main.java tempat user melakukan input dan menampilkan menu yang disediakan
